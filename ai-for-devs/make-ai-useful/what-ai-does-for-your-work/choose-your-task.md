# Choose Your Task

---
## Content

Pick one developer task from this week where a reviewable first pass would help.

Good candidates have source material you can check:

- bug tickets and logs for a triage note
- review notes for a code review comment
- API docs and current usage for a comparison
- merged tickets for release notes
- failing tests for a debugging summary
- design notes for open questions

Choose one task and write down three things:

1. The task
2. The first pass you would ask for
3. The source material or assumptions you would still verify

Example sketch:

- Task: summarize checkout failures before triage
- First pass: likely patterns, affected flows, and evidence for each pattern
- Check: original tickets, logs, failing tests, recent diffs, and assumptions the summary may skip

If you want help shaping the first ask, use Enki AI in the comments and include what source material you would still verify.
