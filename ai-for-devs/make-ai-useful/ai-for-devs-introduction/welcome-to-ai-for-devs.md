# Welcome To AI For Devs

---
## Content

This course helps you use generative AI in developer work without treating it like a source of truth.

Developer work often starts with scattered context: a ticket that skips reproduction steps, a failing CI run, a log excerpt, an API doc, a code review comment, and a product question about the release.

Generative AI can help turn that source material into a draft summary, checklist, comparison, or sharper question.

The useful habit is to treat that output as a first pass. Before using it, verify the important parts against the code, docs, tests, logs, tickets, and product context.

Across this course, you will practice using AI to move faster while keeping the decision grounded in the work itself.
