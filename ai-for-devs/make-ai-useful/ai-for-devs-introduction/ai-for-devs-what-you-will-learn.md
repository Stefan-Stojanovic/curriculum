# What You Will Learn

---
## Content

This course is about making generative AI useful in the parts of developer work that already require judgment.

You will practice how to:

- choose useful context from tickets, logs, docs, tests, metrics, diffs, and review comments
- ask for output that is specific enough to inspect
- spot claims that need evidence
- revise generated drafts before sharing them
- decide what still needs a test, code review, reproduction step, debugging session, or product call

The goal is not to make AI feel impressive. The goal is to make messy context easier to work through while keeping important decisions grounded in the work itself.
