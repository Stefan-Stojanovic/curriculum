# How This Course Works

---
## Content

The lessons are short and practical.

You will work with developer situations: triaging tickets, reading logs, checking API docs, reviewing generated summaries, thinking through tests, interpreting metrics, and drafting release notes.

Some lessons ask you to choose a task. Others ask you to compare a generated first pass with the code, docs, tests, logs, or notes behind it.

When a lesson asks you to try a prompt, use Enki AI in the comments so the activity stays inside the app.

For now, pick one developer task from this week where a clearer first pass would help: summarizing a bug thread, drafting a code review comment, comparing API docs, or turning merged tickets into release notes.
